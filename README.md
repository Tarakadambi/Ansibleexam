# ⚙️ Ansible Exam Project

## 📖 Overview
This project demonstrates automation using Ansible. It includes writing playbooks to configure and manage systems automatically without manual intervention.

The goal of this project is to understand Infrastructure as Code (IaC) using Ansible.

---

## 🚀 What I Did
- Created Ansible playbooks for automation tasks  
- Configured inventory file for managing target hosts  
- Used Ansible modules to automate system configuration  
- Executed playbooks using `ansible-playbook` command  
- Learned how Ansible manages infrastructure without manual setup  
- Practiced configuration management and deployment automation  

---

## 🛠️ Technologies Used
- Ansible  
- YAML  
- Linux environment  
- SSH  
- Virtual machines
